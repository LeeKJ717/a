## 1.0 이 장을 읽기 위한 기본 개념

1장은 바다가 낮았던 시대의 대륙붕을 다룬다. 논문들이 전제로 쓰는 용어를 먼저 정리한다. 이 절의 설명은 일반적인 정의이며 이 장 논문의 수치와는 구분된다.

{{T:1장에서 쓰는 기본 개념}}

| 개념 | 뜻 | 이 장에서 쓰이는 곳 |
|---|---|---|
| 대륙붕(continental shelf) | 대륙 가장자리에서 완만하게 바다로 뻗은 얕은 해저. 바깥 끝(대륙붕 외연)에서 경사가 급해진다. 황해와 동중국해의 대부분이 이에 속한다 | 1.1, 1.4 |
| 해수면(해수준)과 상대 해수면 | 바닷물의 양이 바뀌는 변화(전 지구적)와 땅이 오르내리는 변화를 합친 "그 자리에서 본" 해수면이 상대 해수면이다. 같은 깊이의 시료라도 땅이 움직였으면 해수면 값이 달라진다 | 1.3, 1.5 |
| 해수면 지시자(sea-level indicator) | 옛 해수면과 일정한 관계에서 만들어진 시료나 지형. 이탄은 해수면보다 위, 조간대 조개는 해수면 가까이 또는 아래에서 생긴다고 본다 | 1.2, 1.3 |
| 원지성(autochthonous)과 이동 | 시료가 만들어진 자리에 그대로 있는 것을 원지성이라 한다. 바다가 올라오면서 옮겨졌다면 깊이가 옛 해수면을 가리키지 못한다 | 1.3 |
| 매몰곡(buried valley) | 해수면이 낮을 때 하천이 판 골짜기가 나중에 퇴적물로 메워진 것. 골짜기 바닥 깊이를 옛 해수준의 한계로 읽는다 | 1.3 |
| 음파탐사(탄성파 탐사) | 소리를 해저로 쏘아 지층 경계에서 반사되어 돌아오는 시간으로 지층 모양을 그리는 방법 | 1.4, 1.5 |
| 광자극발광(OSL) 연대 | 모래 알갱이가 마지막으로 햇빛을 본 뒤 쌓인 방사선 피해의 양으로 매몰 나이를 구한다. 이탄이나 조개가 없는 모래층에도 쓴다 | 1.4 |
| 방사성탄소(14C) 연대 | 생물이 죽은 뒤 14C가 줄어든 정도로 나이를 구한다. 달력 연대로 바꾸려면 보정 곡선(IntCal20, Marine20)이 필요하다. 계산은 2.9.6절 참조 | 1.3, 1.4 |
| 수압지각평형(hydro-isostasy) | 바닷물이 늘면 해저가 눌려 가라앉고 땅은 상대적으로 솟는 지각의 조절. 대륙에 가까운 해역과 외해의 해수면 값이 달라지는 원인 | 1.3 |
| 용융수 펄스(MWP) | 빙상이 급하게 녹아 해수면이 빠르게 오른 시기. MWP-1A는 Wang 등(2022)이 14.5∼13.7 ka로 적었다 | 1.5 |
| 조석 모래 능선(tidal sand ridge) | 강한 조류가 대륙붕 위에 쌓은 길쭉한 모래 둔덕. 방향이 조류 방향을 반영한다고 해석한다 | 1.5 |
| 안부(sill)와 해협 | 두 바다 사이의 가장 얕은 곳. 해수면이 안부 깊이보다 내려가면 물길이 닫힌다 | 1.1, 1.6 |

수식을 쓸 때마다 간단한 숫자 예로 끝값까지 계산한다. 이 장의 계산은 1.8절에서 여섯 가지 방법으로 묶어 이론 배경, 의미, 한계, 해결 방안을 붙인다.
