**이 장의 계산을 직접 해 보는 코드.** Otsu 문턱값, EPR, OSL 나이와 오차, 14C 나이의 왕복 계산이다. 숫자는 9.8절의 시연값과 같다.

```python
import math
def otsu(vs):
    n=len(vs); best=(None,-1)
    for t in range(min(vs),max(vs)):
        a=[v for v in vs if v<=t]; b=[v for v in vs if v>t]
        sb=(len(a)/n)*(len(b)/n)*(sum(a)/len(a)-sum(b)/len(b))**2
        if sb>best[1]: best=(t,sb)
    return best
print(otsu([1,2,2,3,3,4,5,6,6,7,7,8,8,9]))   # (4, 4.9591...)
def epr(d1,d2,years): return (d2-d1)/years
print(epr(1200,6100,16))                      # 306.25 m/a
def osl(de,sde,dr,sdr):
    age=de/dr; rel=math.hypot(sde/de,sdr/dr); return age, age*rel
print(osl(5.0,0.5,2.5,0.1))                   # (2.0, 0.2154)
print(osl(4.64,0.55,2.57,0.09))               # (1.805, 0.223) Ma 등 HZ-OSL-115
def c14_age(F,tau=8033): return -tau*math.log(F)
print(c14_age(math.exp(-475/8033)))           # 475.0
```

#### 오쓰 노부유키(大津展之): 영상을 두 덩어리로 나누는 문턱값의 방법

**연결.** Yang 등(2025)은 물과 육지를 가르는 문턱값을 Otsu 방법으로 정했다고 쓰고, 이 방법이 1979년 Nobuyuki Otsu에 의해 제안되었다고 적는다. 아래 서술은 이 책이 읽은 일본어 위키백과 "大津展之" 항목이며 2차 자료이다. 논문의 Otsu와 이 항목의 인물이 같은 사람이라는 것은 이름의 한자와 로마자 표기로 읽었을 뿐 이 책이 서지로 확인하지 못했다.

**생애.** 1969년 도쿄 대학 공학부 계수공학과를 졸업했고 1971년 석사, 1981년 공학박사를 받았다. 1971년 전기시험소(Electrotechnical Laboratory)에 들어갔다. 1992~2010년 쓰쿠바 대학 교수, 2001~2007년 도쿄 대학 교수였고, 2012년 산업기술종합연구소(AIST)에서 정년 퇴직했다.

**수상.** 항목에는 1978년(문턱값 결정에 대한 수상으로 적힘), 1988년, 1998년(IAPR MVA'98 최다 영향 논문상), 2002년(니와 다카야나기상)이 있다. 1988년 수상의 이름은 이 책이 확인하지 못했다.

**이 책이 확인하지 못한 것.** 이 항목에는 방법을 발표한 논문의 연도가 적혀 있지 않았다. 1979년이라는 연도는 Yang 등의 서술이다. 1978년 수상과 1979년 제안이 같은 연구인지는 이 책이 정하지 못한다. 사진은 공용 저작물 여부를 확인하지 못했다.
