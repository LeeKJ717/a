# 제2권 집필 규칙 v1 (모든 집필 에이전트 공통)

책: 『1만 년의 기후와 땅』 제2권 방법편 — 오픈 소스, 공개 데이터셋, 로컬 GPU로 하는 분석. 지은이 이광조, 과학과영성출판사. 독자는 제1권의 계산을 자기 컴퓨터에서 되풀이하려는 사람. 호칭 "이박사님"은 채팅에서만 쓰고 원고에는 쓰지 않는다.

## 절대 규칙
1. 지어내지 않는다. 실습은 이 컨테이너에서 실제로 실행해 결과를 확인한 것만 싣는다. 실행하지 못한 명령·코드는 싣지 않는다. 본문의 모든 출력 숫자는 실행 로그(ms/code/chNN/*.log)에서 옮긴다. 쓰지 않은 숫자를 상상해 적지 않는다.
2. 이 컨테이너에는 GPU가 없다(nvidia-smi 없음). GPU 실행 결과는 싣지 못한다. GPU 코드는 CPU 대체 경로로 실제 실행한 결과만 싣고, GPU에서 잰 시간·메모리는 "z840 실행 필요"로 비워 둔다.
3. 도구·자료의 라이선스와 입수처는 공식 페이지를 WebFetch/WebSearch로 확인한 것만 적는다. 확인하지 못하면 "확인 필요". 셸의 네트워크는 패키지 저장소(pip, npm)와 GitHub 정도만 열려 있고 다른 사이트는 막힌다. 막히면 우회하지 말고 "입수 확인 필요"로 둔다.
4. 제1권 숫자를 재현할 때는 제1권 원고(/home/claude/book/ms/chNN-v1.md)와 계산 스크립트(/home/claude/book/ms/chNN-calc-v1.py)를 읽고 값을 맞춘다. 맞지 않으면 어긋남을 그대로 적는다. 지우지 않는다.
5. 논문 값은 논문에서, 이 책 계산값은 이 책 계산값으로 구분한다. "시연값"(절차를 보이려는 가상 값)은 시연값이라고 쓴다. 쓰지 않는 말: "장난감 예제".
6. 한자 병기 금지, 한자 독음은 한국 독음. 영어 약어는 처음에 풀어 쓴다. 초보자가 따라올 수 있게 낱말을 처음부터 설명한다.
7. 모든 인용은 APA 7판, 본문 (저자, 연도), 장 끝에 참고문헌. 읽지 못한 문헌은 "서지 확인 필요".
8. 장 끝 "실습 장부": 실습 번호, 내용, 실행 환경(파이썬·라이브러리 버전), 걸린 시간, 결과, 수준(직접 실행 확인 / 시연값 / 미결).

## 장 구성 (목차안 5절)
장 안내 → 기본 개념과 이론 상자 → 실습(입력, 명령, 기대 결과, 확인) → 점검(제1권 계산과 맞는가) → 한계와 함정 → 도구·데이터 입수처·더 읽을 책 → 실습 장부 → 참고문헌.
분량: 공백 제외 한글 기준 25,000자 이상을 목표로 하되 채우려고 늘리지 않는다. 늘릴 수 없으면 짧아도 정직하게 쓰고 부족한 근거는 "근거 확인 필요"로 적는다. 한글 글자 수는 python len()으로 센다(wc -m은 틀림).
