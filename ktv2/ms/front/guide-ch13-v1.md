## 13장 안내: 로컬 언어 모델로 논문 읽기

**이 장이 묻는 것.** 인터넷으로 보내지 않고 자기 컴퓨터에서 돌리는 언어 모델(로컬 언어 모델)에게 논문의 표와 서술을 옮겨 적게 하고, 그 결과를 원문과 대조하게 하면 제1권의 "원문 쪽 확인 필요"를 줄일 수 있는가. 줄일 수 있다면 모델이 없는 사실을 지어낸 것(환각)을 어떻게 걸러 내는가를 다룬다.

**먼저 알아 둘 것.** 이 책을 쓴 컨테이너에서는 모델을 한 번도 실행하지 못했다. 파이썬 라이브러리(llama-cpp-python)는 설치되고 불러졌으나 모델 가중치(모델의 계산에 쓰는 숫자 묶음)를 입수할 길이 없었다. 그래서 이 장에는 모델이 낸 출력이 하나도 없다. 대신 모델과 무관하게 돌아가는 환각 점검기를 만들어 실제로 실행했고, 모델이 틀리게 쓴 값을 일부러 섞은 시연값으로 점검기를 시험했으며, 제1권 11장의 장부에 점검기를 돌려 제1권이 찾은 어긋남을 자동으로 찾는지 확인했다.

**길잡이.**

- 13.2절: 모델을 돌릴 수 있는지 시도한 것과 결과를 그대로 적는다(실습 13-1~13-4). 설치는 성공, 가중치 입수는 실패.
- 13.3절: 라이선스와 로컬 실행 사양, 가중치 메모리 산술(실습 13-5). 공식 페이지를 읽지 못한 것은 "확인 필요"이다.
- 13.4절: 환각과 점검의 기본 개념, 점검 절차(그림 13-1).
- 13.5절: 점검기의 구조와 단위 시험(실습 13-6).
- 13.6~13.8절: 시연 출력 점검(실습 13-7, 그림 13-2), 원문 범위(실습 13-8), 두 번 실행 비교(실습 13-9).
- 13.9절: 제1권 11장 장부에 점검기를 돌린 결과. 찾은 것, 못 찾은 것, 새로 지적한 것(실습 13-10, 그림 13-3, 13-4).
- 13.10절: 모델 호출부 코드(Ollama 서버). 실습 13-11은 문법 검사와 실패 경로까지 실행했고, 실습 13-12와 13-13은 "z840 실행 필요"로 비워 두었다.
- 13.11절 이후: 한계, 도구와 이용 조건, 실습 장부.

**이 장의 숫자.** 실습 13개(직접 실행 확인 11개, 미결 2개), 그림 4개. 점검기의 한 번 실행은 1초가 걸리지 않는다. 가장 오래 걸린 것은 llama-cpp-python의 설치(6분 41초)였다.

**꼭 알아 둘 것.** 점검기가 통과시킨 줄이 맞다는 뜻은 아니다. 점검기는 글자와 산술만 본다. 숫자를 엉뚱한 항목에 붙이거나 부정문을 뒤집은 오류는 시연에서 4개 중 4개를 못 찾았다. 점검기가 지적한 줄도 모델의 오류라는 뜻이 아니다. 원문 자체의 어긋남(제1권이 찾은 23 = 21 + 5)을 충실히 옮겨도 점검기는 지적한다.

**앞뒤 장과의 연결.** 2장(논문과 자료를 모으는 법)의 표 추출은 열이 흩어지는 문제를 다룬다. 이 장의 표 합 점검은 그 문제의 검산에 쓸 수 있다. 10장(로컬 GPU 입문)의 메모리 계산은 모델 가중치의 크기를 가늠하는 13.3절에 쓰인다.

**읽는 팁.** 모델이 없어도 13.3~13.9절의 실습 13-5~13-10은 `bash run-all-v1.sh` 한 줄로 되풀이할 수 있다(표준 라이브러리만 쓴다). 13.10절의 코드는 Ollama 서버가 있는 컴퓨터에서만 돌아간다.
