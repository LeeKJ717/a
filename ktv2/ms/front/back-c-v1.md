# 부록 B. 라이선스와 입수처의 확인 상태

아래 표는 장마다 이 책이 공식 페이지에서 확인한 것과 확인하지 못한 것을 모은 것이다. "확인"은 이 책이 해당 페이지를 읽었다는 뜻이다. 소프트웨어의 라이선스가 자료의 이용 조건을 뜻하지는 않는다.
