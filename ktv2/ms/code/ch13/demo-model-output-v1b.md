## 1. 시료 흐름
논문은 여섯 유적에서 138명의 치아와 뼈를 얻었다.
형태로 남성이라 본 것이 78명이었고, 아멜로제닌 분석으로 8명이 여성으로 판정되어 남성 70명이 남았다(78 − 8 = 70).
70명 중 47명이 재현 가능한 결과를 냈다.
재현 비율은 47/70 = 67.1% 이다. [계산]
STR은 17개 자리를 시험했고 47명 중 22명이 두 번의 독립 추출에서 3개 이상의 자리 결과를 냈다.
논문은 SNP 18개를 위계적으로 시험했다.
증폭 조각은 100~200 bp 로 했다.
